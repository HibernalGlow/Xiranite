# NeoView File Card 标签导航

## 领域契约

- `directory` 是可替换标签：历史、书签和普通浏览请求可以复用当前浏览器会话。
- `search` 与 `efu` 是受保护标签：会替换当前列表的请求必须打开新标签。
- 历史或书签的穿透激活遇到受保护标签时由 File Card 明确拒绝，调用方继续使用既有的无活动会话回退流程。
- `pinned` 只表示目录标签的配置持久化，不参与受保护策略。
- 刷新、排序、过滤、删除等针对当前列表的操作不属于标签替换，继续作用于当前搜索或 EFU 会话。

## 依赖选择

标签导航策略使用 `@xstate/store` 的事件转换与 `can` 守卫。该包由 XState 团队维护、采用 MIT 许可证，当前安装包无运行时依赖，核心小于 1 KB gzip。它只负责执行 Xiranite 定义的 `browse`、`activate`、`navigate` 转换，不替代目录会话、搜索快照或 EFU 领域模型。

评估过但未采用：

- Radix Tabs：项目已使用，适合可访问 UI，不提供标签替换策略。
- Zustand：项目已使用，适合共享状态，但不提供事件可用性守卫；本策略不需要新增全局状态。
- 完整 XState：支持状态图和 Actor，但本策略没有并发状态或长生命周期 Actor，运行时与 API 面明显超出需求。
- Robot3：体积小，但维护活跃度和类型工具链不及 XState Store。

## 验证门禁

- 纯状态测试覆盖三种标签分类、外部浏览路由、激活拒绝和受保护路径导航。
- Vitest Browser Mode 覆盖 EFU 直接新建标签、搜索/EFU 锁图标、受保护标签不被外部浏览覆盖、搜索列表保留，以及普通目录标签继续复用。
