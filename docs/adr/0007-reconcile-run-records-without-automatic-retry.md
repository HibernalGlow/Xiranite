# Reconcile run records without automatic retry

Comfygure persists Run Records and reconciles owned prompt IDs against ComfyUI queue and history after restart. Completed and active prompts recover their observed state, unsubmitted jobs remain resumable, and submitted prompts missing from both sources become explicitly retryable unknowns rather than being resubmitted automatically and risking duplicate outputs. For each submitted job, the Run Record retains the resolved Generation Job, actual Prompt Graph, compiler and Generation Profile versions, and normalized Result References containing prompt and output-node identity, ComfyUI file locator, resolved local path, file size, and availability state. This metadata is the recovery authority; node-specific history payloads, embedded image metadata, and workflow sidecars are supplementary evidence only.
