## 先整理什么

### 1. 武陵地图

优先记录以下内容，而不是直接复制地图图片：

- 区域边界、主干道路和高差表现方式
- 城区、工业区、野外区域的底色差异
- 资源点、传送点、任务点、危险点的符号形状
- 标签的字号、描边、背景透明度和碰撞关系
- 地图缩放时哪些标记隐藏、聚合或改变尺寸

### 2. 图标

建立图标观察表，字段建议为：

```text
name | category | silhouette | primary-color | rarity-color | outline | background-shape | notes
```

Xiranite 中建议重新绘制为自有 SVG 或 CSS 图形，只参考：

- 外轮廓的几何结构
- 线宽和切角习惯
- 稀有度色彩关系
- 图标在 16px、20px、24px 下的识别性

### 3. UI 面板

重点观察：

- 深色半透明面板与浅色技术标注的对比
- 细边框、角标、分割线和状态灯
- 横向信息条、列表项和地图浮层的密度
- 警告色、选中态、禁用态和加载态
- 中文标题与英文/数字辅助信息的排版比例

## 下载和版权边界

### 可以做

- 将来源链接、截图和个人观察笔记放进本地参考目录。
- 为自己的 UI 重新绘制相似功能的地图标记、边框、面板和图标。
- 在设计文档中引用来源页面并注明“仅作视觉参考”。

### 不建议做

- 把 AKEData、Wiki、攻略站的原图或原始图标直接复制到应用发布包。
- 直接依赖第三方站点的图片 URL 作为运行时资源。
- 没有确认许可证就复制 Open Endfield Map 的代码、地图数据或数据库内容。
- 使用原作 Logo、角色立绘或官方宣传图制造“官方合作/官方客户端”的观感。

## Xiranite 落地建议

第一阶段只实现一套“受武陵工业地图启发”的自有视觉令牌：

```text
surface:      #12171A / #1B2326
panel:        #202A2D / 88% opacity
line:         #6D7B79
text:         #E4E9E5
muted:        #8D9A96
accent:       #D9A441
warning:      #D56B45
success:      #7FAE8B
map-terrain:  #2A3533
map-road:     #9C9A86
```

颜色只是第一版起点，不能视为终末地官方色值。图标和边框应使用 Xiranite 自己的命名、SVG 路径和资源文件，避免运行时读取上述站点。
