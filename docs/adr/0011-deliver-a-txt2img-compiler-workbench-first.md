# Deliver a txt2img compiler workbench first

Comfygure's first Fixed UI is a complete txt2img compiler workbench rather than a full migration of any reference application. It covers Project Document lifecycle, local ComfyUI Target status, Native and Template Compilation, API-template import and binding confirmation, batch prompt expansion and Run Plan preview, model and Generation Profile selection, dynamic LoRA resolution and strengths, sampler and image parameters, compatibility preflight, bounded run controls, progress, diagnostics, and indexed results. Img2img, inpainting, canvas editing, ControlNet, style transfer, face refinement, upscaling, standalone gallery, model hub, and artist or character browsers remain in reference inventories for later feature slices instead of delaying the first usable compiler path.
