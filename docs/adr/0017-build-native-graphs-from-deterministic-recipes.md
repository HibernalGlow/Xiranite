# Build native graphs from deterministic recipes

Native Compilation will use versioned Compiler Recipes and a generic Prompt Graph builder rather than inferring workflow semantics from the connected server. A recipe emits concrete nodes and references from resolved intent, typed helpers cover the supported stable core surface, and data-defined Node Descriptors cover profile-selected or custom classes. Live `/object_info` supplies capability, field, port, and enum evidence for Compatibility Preflight only: additive optional changes may remain compatible, while missing classes, required fields, ports, or invalid values block compilation with a structured difference. This keeps output reproducible across runs while still detecting local ComfyUI and custom-node drift before submission.
